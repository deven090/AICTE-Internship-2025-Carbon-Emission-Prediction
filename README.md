
# Carbon Emission prediction

This project aims to predict multiple carbon emission indicators using machine learning techniques, specifically MultiOutputRegressor wrapped around a RandomForestRegressor. It was developed as part of a one-month AICTE Virtual Internship sponsored by Shell in June 2025.

Link to the Model: https://drive.google.com/file/d/1ATibxUK-00ScB2JTXQDIU_9ji79CUG9K/view?usp=drive_link
## Overview

Climate change and global warming are among the most urgent environmental challenges today. Accurate prediction of carbon emission levels can help policymakers, industries, and environmentalists take data-driven actions for reducing greenhouse gas emissions and ensuring sustainable practices.

In this project, we:

- data_presentation.ipynb: Loaded and cleaned the carbon emissions dataset, handling missing values and ensuring consistent formatting.

- Data_exploration.ipynb: Performed exploratory data analysis using statistical summaries and visualizations to understand feature relationships.

- model_building.ipynb: Built, trained, and evaluated machine learning models to predict carbon emissions based on selected features.

##  Technologies Used

- *Python 3.12*
- *Pandas, NumPy* – Data handling
- *Scikit-learn* – Machine learning model and evaluation
- *Matplotlib, Seaborn* – Data visualization
- *Jupyter Notebook* – Interactive experimentation
##  Predicted Carbon Emission Indicators

The model predicts multiple emission-related parameters, including:

- CO2 (Carbon Dioxide) from year 1990 to 2011
## Model performace

The model was evaluated using:

- Performance Metrics such as Mean Squared Error (MSE), Root Mean Squared Error (RMSE), Mean Absolute Error (MAE), and R² Score.
- Train-Test Split to assess generalization capability.

Performance was acceptable across all parameters
